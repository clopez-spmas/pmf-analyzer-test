PASO 1 DE 5

Datos de la evaluación

Identifica el estudio y la tarea que se va a analizar.

PASO 2 DE 5

Vídeos y archivos Kinovea

Indica cuántos vídeos pertenecen a esta misma tarea y carga el JSON Kinovea de cada uno.

Número de vídeos

PASO 3 DE 5

Asignación de marcadores y análisis

Inicia el análisis y asigna los marcadores Kinovea a los puntos anatómicos de cada vídeo.

Importante La asignación se realiza de forma independiente para cada vídeo. El programa conservará el mapping dentro del proyecto.
Pulsa «Iniciar asignación y analizar» cuando hayas cargado todos los vídeos.
PASO 4 DE 5

Resultados por sección corporal

Revisa los resultados, la trazabilidad y completa las confirmaciones técnicas que solicite el programa.

Pendiente de análisis.
PASO 5 DE 5

Guardar o recuperar el proyecto

El proyecto JSON conserva los archivos Kinovea incorporados, cálculos, confirmaciones y trazabilidad.

Proyecto nuevo.
Al volver a abrir un proyecto No tendrás que volver a cargar los archivos Kinovea originales si sus datos ya estaban incorporados al JSON del proyecto.
