# Documentación de Posturas Forzadas

Esta carpeta contiene la documentación visible para las personas usuarias del programa.

## Archivo enlazado desde el programa
- `Instrucciones_Uso_Programa_Posturas_Forzadas.pdf`

El botón **Instrucciones de uso** abre siempre ese archivo.

## Cómo actualizar las instrucciones
1. Edite su documento maestro en Word.
2. Exporte la versión definitiva a PDF.
3. Sustituya en esta carpeta el archivo `Instrucciones_Uso_Programa_Posturas_Forzadas.pdf`.
4. Mantenga exactamente el mismo nombre y la misma ubicación.

Mientras se conserve ese nombre y ruta, no es necesario modificar el código del programa.
